Provably Safe.

Evergreen brings explicit contracts, checked invariants, and control over memory into one language. Write down what must hold. Let the compiler check that it does.

type NonZero struct {data: usize} where data != 0;

impl NonZero {
    fn new(x: usize) -> Self
        where x != 0
    {
        return NonZero {data: x};
    }
}

fn main() -> usize {
    let my_nonzero = NonZero::new(10);
    0
}

The compiler checks the invariant when the value is built.

The Core Idea

More intent in the source.
Fewer assumptions in your head.

01 /

Say what must be true.

Put preconditions, postconditions, and data invariants beside the code they describe. They become obligations the compiler checks.

fn increment(n: usize) -> usize
    where n < usize::MAX
    ensures result > n
{
    n + 1
}

Every call must establish the precondition.

02 /

Keep control of memory.

Work with explicit layouts, ownership, and borrowed references. Evergreen tracks when a memory plane is live and which uses remain valid.

let value: usize = 1;
let first = &value;
let second = &value;
*first = 10;
proof same: *second == 10;

A write is visible through both live borrows.

03 /

Carry less into runtime.

Proofs and ideal computations are erased after checking. Executable code keeps the work it needs to do.

ideal let expected: nat = 42;
let value: usize = 42;
proof matches:
    nat(value) == expected;

The ideal binding and proof are erased. The value stays.
